# Jutsu de Shinobi Striker par nature et par clan

Les 256 jutsu de Shinobi Striker (noms officiels FR), regroupés par **nature de chakra** puis par **clan / lignée** du personnage SS qui les utilise. Un jutsu peut apparaître dans plusieurs natures (ex. Katon + Fûton). Colonne « Dans NARUTO-CLASH » : kit (rang) où il est utilisé aujourd'hui (`tools/ss_kits.txt`). Données complètes (descriptions, icônes) : `data/progression/ss_jutsu_groups.json`. Régénérer : `powershell -File tools\ss_jutsu_groups.ps1`.
