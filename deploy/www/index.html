Installation

  1. Télécharge le launcher et mets-le dans son propre dossier (ex. Documents\NinjaBattle).
  2. Lance-le. Si Windows affiche un écran bleu : Informations complémentaires → Exécuter quand même.
  3. Le launcher télécharge le jeu puis clique PLAY.
  4. Menu → Online 1v1 ou Online 2v2, ou entraîne-toi contre les bots.
