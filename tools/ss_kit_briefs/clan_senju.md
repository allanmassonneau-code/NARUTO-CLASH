## clan_senju_d_coup_de_pied_marteau  [rang D]
- Nom SS : Coup de pied marteau
- Jutsu SS : Tsunade_01 (type Melee, catégorie Normal, puissance 3/5, portée 2/5, dossier /Game/Weapons/Ninjutsu/HeavenKickPain)

## clan_senju_b_enceinte_de_bois  [rang B]
- Nom SS : Mokuton : Enceinte de bois
- Jutsu SS : Yamato_02 (type Technical, catégorie Normal, puissance 3/5, portée 1/5, dossier /Game/Weapons/Ninjutsu/DomedWall)
- Recharge : 15 s, chakra 28
- Description SS : Cette technique crée un mur de bois qui disparaît au bout d'un certain temps ou après avoir subi un certain nombre de dégâts. Toutes les cibles qui sont touchées lors de la création du mur subissent des dégâts.

## clan_senju_a_dragon_de_bois  [rang A]
- Nom SS : Mokuton : Dragon de bois
- Jutsu SS : Hashirama_02 (type Ranged, catégorie Normal, puissance 2/5, portée 5/5, dossier /Game/Weapons/Ninjutsu/WoodenDragon)
- Recharge : 16 s, chakra 40
- Description SS : Jutsu qui permet de créer un gigantesque dragon à partir d'un arbre. Il se rue sur ses cibles et réduit leur jauge de technique secrète tout en réduisant son propre délai de récupération. L'utilisateur récupère des PV en fonction des dégâts infligés.

## clan_senju_s_croissance_luxuriante_de_la_foret  [rang S]
- Nom SS : Mokuton : Croissance luxuriante de la forêt
- Jutsu SS : Yamato_03 (type Ranged, catégorie FinishMove, puissance 2/5, portée 3/5, dossier /Game/Weapons/Ninjutsu/DeepForestEmergence)
- Recharge : 32 s, chakra 70
- Description SS : Cette technique crée des arbres que l'utilisateur peut manipuler. Les cibles touchées sont paralysées pendant un certain temps ou jusqu'à ce qu'elles soient attaquées. Leur défense est ensuite réduite.

## Substitution du kit (info) : Clone de bois — Crée un clone de bois de l'utilisateur, ce qui lui permet de changer de position avec lui et d'éviter les attaques. Lorsque la technique réussit, le clone capture l'ennemi et le ralentit. Long délai de récupération.
