## clan_fuma_d_technique_des_shurikens_uchiwa_oboroguru  [rang D]
- Nom SS : Technique des shurikens Uchiwa : Oboroguruma
- Jutsu SS : D33NJ2 (type Ranged, catégorie Normal, puissance 1/5, portée 5/5, dossier /Game/Weapons/Ninjutsu/D33NJ2)
- Recharge : 11 s, chakra 12
- Description SS : Lancez un Moulin d'ombre, puis ramenez-le en appuyant sur une touche. Augmente la vitesse de déplacement, le suivi de vos attaques et la distance d'esquive. Révèle les ennemis invisibles et scelle les ninjutsu de la cible. Désactive aussi leur permutation.

## clan_fuma_c_bombe_du_moulin_d_ombre  [rang C]
- Nom SS : Bombe du moulin d'ombre
- Jutsu SS : D83NJ2 (type Melee, catégorie Normal, puissance 2/5, portée 2/5, dossier /Game/Weapons/Ninjutsu/D83NJ2)
- Recharge : 10 s, chakra 20
- Description SS : L'utilisateur se transforme en un moulin d'ombre qu'un clone utilise ensuite pour attaquer. Une fois activé, l'utilisateur peut déplacer le shuriken librement, infligeant des dégâts à toutes les cibles touchées. Une activation supplémentaire désactivera la transformation et l'utilisateur attaquera l'adversaire avec un coup de pied.

## clan_fuma_s_parchemins_explosifs_autorepliquants  [rang S]
