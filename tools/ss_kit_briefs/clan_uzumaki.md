## clan_uzumaki_d_orbe_tourbillonnant  [rang D]
- Nom SS : Orbe tourbillonnant
- Jutsu SS : Naruto_01 (type Melee, catégorie Normal, puissance 2/5, portée 2/5, dossier /Game/Weapons/Ninjutsu/Rasengan)
- Recharge : 8 s, chakra 12

## clan_uzumaki_c_connexion_d_orbes_tourbillonnants  [rang C]

## clan_uzumaki_b_hiraishin  [rang B]
- Nom SS : Hiraishin
- Jutsu SS : Minato_01 (type Technical, catégorie Normal, puissance 0/5, portée 0/5, dossier /Game/Weapons/Ninjutsu/FlyingRaijin)
- Recharge : 8 s, chakra 28
- Description SS : Cette technique permet de se téléporter. Après avoir lancé un kunai, l'utilisateur peut se téléporter jusqu'à celui-ci. La défense et l'attaque sont augmentées après avoir lancé le kunai.

## clan_uzumaki_a_hiraishin_niveau_2  [rang A]
- Nom SS : Hiraishin : Niveau 2
- Jutsu SS : Minato_02 (type Melee, catégorie Normal, puissance 2/5, portée 3/5, dossier /Game/Weapons/Ninjutsu/FlyingRaijinLv2)
- Recharge : 12 s, chakra 40
- Description SS : Une attaque-surprise qui utilise le Hiraishin. L'utilisateur lance un kunai sur sa cible. S'il la touche, il se téléporte au-dessus de la cible et lance un Orbe tourbillonnant. Les ennemis touchés seront ralentis et ne pourront pas utiliser de Permutation pendant une courte période. Le kunai touchera aussi les cibles qui ne peuvent pas être attaquées à cause de jutsu visuels.

## clan_uzumaki_s_sceau_emprisonnant  [rang S]
- Nom SS : Fûinjutsu : Sceau emprisonnant
- Jutsu SS : ENTRY_11 (type Technical, catégorie FinishMove, puissance 0/5, portée 1/5, dossier /Game/Weapons/Ninjutsu/BarrierMethod)
- Recharge : 32 s, chakra 70
- Description SS : Cette technique d'emprisonnement immobilise la cible. Le sceau émane de l'utilisateur et paralyse toutes les cibles à portée.

## Substitution du kit (info) : Multiclonage — Crée un clone de l'utilisateur, ce qui lui permet de changer de position avec lui et d'éviter les attaques. Le clone dure un certain temps, ce qui aide à se cacher. Long délai de récupération.
