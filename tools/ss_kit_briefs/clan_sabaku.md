## clan_sabaku_a_sarcophage_de_sable  [rang A]
- Nom SS : Sarcophage de Sable
- Jutsu SS : D72NJ2 (type Ranged, catégorie Normal, puissance 3/5, portée 5/5, dossier /Game/Weapons/Ninjutsu/D72NJ2)
- Recharge : 15 s, chakra 40
- Description SS : Une main de sable prend forme et immobilise les ennemis. Enterrement du désert infligera plus de dégâts à chaque utilisation successive, mais se réinitialise quand l'utilisateur est mis K.O.

## clan_sabaku_s_grand_mausolee_de_sable  [rang S]
- Nom SS : Grand mausolée de sable
- Jutsu SS : Gaara_03 (type Ranged, catégorie FinishMove, puissance 5/5, portée 3/5, dossier /Game/Weapons/Ninjutsu/SandBurialGiant)
- Recharge : 32 s, chakra 70
- Description SS : Cette technique piège la cible dans le sable et la rend immobile. Quand le sable disparaît, il explose, infligeant des dégâts et augmentant le temps de réapparition.

## Substitution du kit (info) : Clone de sable — Crée un clone de sable de l'utilisateur, ce qui lui permet de changer de position avec lui et d'éviter les attaques. Le clone peut aussi immobiliser et paralyser les ennemis. Long délai de récupération.
