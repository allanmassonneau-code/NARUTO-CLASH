# Kit clan_hoshigaki -> content/techniques/clans/hoshigaki.gd

## clan_hoshigaki_d_requin_elementaire_aqueux  [rang D]
- Nom SS : Suiton : Requin élémentaire aqueux
- Jutsu SS : Kisame_01 (type Ranged, catégorie Normal, puissance 1/5, portée 5/5, dossier /Game/Weapons/Ninjutsu/SharkBomb)
- Recharge : 14 s, chakra 12
- Description SS : Cette technique tire des projectiles d'eau en forme de requins. Après avoir tourné autour de l'utilisateur, les projectiles partent vers la cible. S'ils la touchent, ils réduisent le nombre de ninjutsu utilisables par la cible.

## clan_hoshigaki_c_voyage_souterrain  [rang C]
- Nom SS : Doton : Voyage souterrain
- Jutsu SS : Kisame_02 (type Technical, catégorie Normal, puissance 0/5, portée 0/5, dossier /Game/Weapons/Ninjutsu/SubterraneanVoyage)
- Recharge : 23 s, chakra 20
- Description SS : Cette technique liquéfie le sol et permet à l'utilisateur de le traverser. Quand il est dans le sol, l'utilisateur ne subit aucun dégât et il récupère des PV, mais il ne peut pas attaquer.

## clan_hoshigaki_b_pilier_d_eau  [rang B]
- Nom SS : Suiton : Pilier d'eau
- Jutsu SS : D24NJ1 (type Technical, catégorie Normal, puissance 2/5, portée 1/5, dossier /Game/Weapons/Ninjutsu/D24NJ1)
- Recharge : 15 s, chakra 28
- Description SS : Cette technique génère une colonne d'eau sur le lanceur, neutralisant les attaques ennemies. Les alliés peuvent entrer dans la colonne. Les ennemis qui la touchent lorsqu'elle apparaît sont envoyés en l'air en subissant des dégâts. Une action supplémentaire permet de transformer la colonne d'eau et d'utiliser Suiton : Dragon aqueux.

## clan_hoshigaki_a_jutsu_secret_deploiement_aqueux_fatal  [rang A]
- Nom SS : Jutsu secret : Déploiement aqueux fatal
- Jutsu SS : D27NJ2 (type Ranged, catégorie Normal, puissance 2/5, portée 1/5, dossier /Game/Weapons/Ninjutsu/D27NJ2)
- Recharge : 8 s, chakra 40
- Description SS : Forme une flaque d'eau sous les pieds de l'utilisateur qui emprisonne les ennemis et leur inflige des dégâts avec des éclats de glace. À l'impact, scelle les ninjutsu et augmente les dégâts subis par les cibles affectées quand elle sont attaquées.

## clan_hoshigaki_s_grand_requin_aqueux  [rang S]
- Nom SS : Suiton : Grand requin aqueux
- Jutsu SS : Kisame_03 (type Ranged, catégorie FinishMove, puissance 5/5, portée 5/5, dossier /Game/Weapons/Ninjutsu/SuperSharkBomb)
- Recharge : 32 s, chakra 70
- Description SS : Cette technique tire une balle d'eau géante qui a la forme d'un requin. Si elle touche la cible, elle réduit le nombre de ninjutsu qu'elle peut utiliser.

## Substitution du kit (info) : Clonage aqueux — Crée un clone aqueux de l'utilisateur, ce qui lui permet de changer de position avec lui et d'éviter les attaques. Cette technique réduit aussi la défense de la cible.
